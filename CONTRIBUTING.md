# Como Contribuir / How to Contribute

---

## 🇧🇷 Português

Quer contribuir com este projeto enviando suas próprias modificações? Siga o passo a passo abaixo. Você vai precisar de uma conta gratuita no [GitHub](https://github.com).

### Passo a passo

1. **Acesse o repositório**
   Abra a página deste repositório no GitHub.

2. **Faça um Fork**
   No canto superior direito da página, clique no botão **"Fork"**. Isso cria uma cópia completa do repositório na sua própria conta do GitHub.

3. **Edite o arquivo no seu fork**
   Dentro do repositório forkado (agora na sua conta), navegue até o arquivo que deseja modificar (ex: `car_profiles.json`) e clique em **"Add file" → "Upload files"** para subir a versão atualizada do seu computador.

4. **Commite as mudanças**
   Escreva uma mensagem curta explicando o que foi alterado (ex: "Adiciona perfil do carro X") e confirme o commit. Como é a sua cópia própria, não há restrição de branch protegida.

5. **Abra o Pull Request (PR)**
   O GitHub vai mostrar um banner com um botão **"Contribute"** ou **"Open pull request"**. Clique nele — o GitHub compara automaticamente seu fork com o repositório original.

6. **Preencha e envie o PR**
   Escreva um título e uma descrição explicando sua contribuição, e clique em **"Create pull request"**. Isso envia sua solicitação para o mantenedor do projeto.

7. **Aguarde a revisão**
   O mantenedor vai revisar suas mudanças. Se estiver tudo certo, ele vai aprovar (merge). Caso contrário, pode pedir ajustes — fique de olho nos comentários do PR.

### Dicas

- Antes de enviar, confira se o arquivo está no formato correto (ex: JSON válido).
- Descreva claramente o que mudou na sua contribuição — isso agiliza a revisão.
- Se tiver dúvidas, abra uma *Issue* no repositório antes de enviar o PR.

## 🇬🇧 English

Want to contribute to this project by submitting your own changes? Follow the steps below. You'll need a free [GitHub](https://github.com) account.

### Step-by-step

1. **Go to the repository**
   Open this repository's page on GitHub.

2. **Fork it**
   In the top-right corner of the page, click the **"Fork"** button. This creates a full copy of the repository under your own GitHub account.

3. **Edit the file in your fork**
   Inside your forked repository, navigate to the file you want to modify (e.g. `car_profiles.json`) and click **"Add file" → "Upload files"** to upload the updated version from your computer.

4. **Commit your changes**
   Write a short message describing what you changed (e.g. "Add profile for car X") and confirm the commit. Since it's your own copy, there's no protected branch restriction.

5. **Open a Pull Request (PR)**
   GitHub will show a banner with a **"Contribute"** or **"Open pull request"** button. Click it — GitHub will automatically compare your fork with the original repository.

6. **Fill out and submit the PR**
   Write a title and description explaining your contribution, then click **"Create pull request"**. This sends your submission to the project maintainer.

7. **Wait for review**
   The maintainer will review your changes. If everything looks good, they'll approve and merge it. Otherwise, they may request changes — keep an eye on the PR comments.

### Tips

- Before submitting, double-check that your file is in the correct format (e.g. valid JSON).
- Clearly describe what you changed in your contribution — this speeds up the review process.
- If you have questions, open an *Issue* in the repository before submitting your PR.
